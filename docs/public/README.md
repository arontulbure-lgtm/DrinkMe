# DrinkMe public legal pages (static site)

Generated by `node scripts/build-public-pages.mjs` from the drafts in `docs/legal/`. **Do not edit the HTML by hand** – change the Markdown in `docs/legal/` and run the script again. No dependencies, no JavaScript, no external assets; CSS is inline in every page (DrinkMe colours `#000000`, `#8B5FBF`, `#1F2937`), mobile-friendly, with a print style.

Every page shows the banner **"Draft – pending legal review"** / **"Ciornă – în curs de revizuire juridică"**, the last-updated date and the draft version from the first line of the source file. Pages also carry `<meta name="robots" content="noindex">`. When the lawyer signs off (decision D-01, recorded in `docs/legal/CHANGELOG.md`), change the banner text and remove `noindex` in the script, set the effective dates in the sources, and rebuild.

## Layout

```
index.html                 both languages, main documents
en/index.html, ro/index.html   all documents per language
{en,ro}/<key>.html         one page per document
```

References to other drafts inside a document become links to the page in the same language; references to internal records (`docs/legal/internal/…`, code paths) are shown as "internal record (not published)".

## Paths with or without `.html`

`docs/legal/CODE_GAPS_PLAN.md` T-01 expects `<base>/{en,ro}/<doc>` (no extension). Two options for the developer of T-01:
1. **Recommended:** `getLegalUrl` appends `.html` (`${base}/${locale}/${doc}.html`). Works on every static host with no configuration.
2. Extensionless URLs: works without configuration on **GitHub Pages**, **Netlify** and **Cloudflare Pages** (they serve `privacy.html` for `/privacy`). **Firebase Hosting** needs `"cleanUrls": true` in `firebase.json`; **S3/CloudFront**, nginx or Apache need a rewrite (`try_files $uri $uri.html =404;` for nginx).

Store URLs (privacy policy, account deletion) should always use the `.html` form, which works everywhere.

## Hosting (decision D-06)
Any static host serving this folder as the site root works. GitHub Pages: publish the `docs/public` folder (for example from a separate public repository or a `gh-pages` branch containing only this folder – publish only this folder, not the whole repository). Then set `EXPO_PUBLIC_LEGAL_BASE_URL` to the site root, without a trailing slash.

## Rebuild
```
node scripts/build-public-pages.mjs
```
Rebuild after every change to `docs/legal/*.md` and commit the generated HTML with the source change.
